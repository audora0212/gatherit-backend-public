# 설계 결정 기록

구현 당시의 선택과 그 제약을 남깁니다. 채택된 결정과 아직 구현하지 않은 제안을 구분합니다.

| 기록 | 내용 | 상태 |
|---|---|---|
| [0001](0001-modular-monolith-over-msa.md) | 도메인 패키지로 나눈 단일 Spring Boot 배포 유지 | 채택 |
| [0002](0002-direct-apns-fcm-over-expo-push.md) | 원격 푸시를 APNs/FCM으로 직접 전송 | 채택 |
| [0003](0003-ai-service-msa-split.md) | AI 추출만 별도 서비스로 분리할 조건과 책임 범위 | 제안 (미분리) |

현재 AI 추출과 일정 저장은 같은 Spring Boot 애플리케이션 안에 있습니다. 0003의 서비스 간 계약은 운영 API가 아닙니다. 패키지 분리는 별도 모듈의 의존성 경계가 강제된다는 뜻이 아닙니다.
